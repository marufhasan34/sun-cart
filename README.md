# 🛒 SunCart - Modern E-Commerce Web App

## 📌 Project Overview
SunCart is a modern e-commerce web application built with Next.js. It allows users to browse products, view product details, and authenticate using email/password or Google login. The project focuses on smooth UI/UX and fast performance.

## ✨ Key Features

- 🔐 User Authentication (Login / Register)
- 🔑 Google Login Integration
- 🛍️ Product Listing Page
- 📄 Product Details Page
- ⭐ Product Rating System
- 🔔 Toast Notifications for actions
- 🎨 Smooth UI animations using Animate.css
- 📱 Fully Responsive Design
- ⚡ Fast and optimized performance

---

## 🧰 Tech Stack

- Next.js (App Router)
- React.js
- Tailwind CSS
- HeroUI (@heroui/react)
- React Toastify
- Animate.css
- React Icons / Iconify
- Custom Authentication Client (authClient)
